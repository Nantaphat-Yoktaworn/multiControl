Connect Your Mac & Windows PC

Run these pre-configured 1-line commands on each computer (auto-pairs with this server)

Network Route:
 Step 1: Run on your Mac (Master Keyboard & Mouse) 
curl -fsSL http://192.168.1.100:8765/install.sh | bash

Installs the Quartz EventTap agent into ~/.multicontrol, adds a MultiControl.command shortcut to your Desktop, and puts the MultiControl icon in your macOS Menu Bar. Grant Accessibility permission when macOS prompts you.

⊞ Step 2: Run on your Windows PC (PowerShell) 
irm http://192.168.1.100:8765/install.ps1 | iex

Installs the Per-Monitor DPI-aware Win32 SendInput receiver into %USERPROFILE%\.multicontrol, creates a Desktop launcher, opens UDP port 8767 for sub-millisecond P2P input, and starts in the Windows System Tray.
